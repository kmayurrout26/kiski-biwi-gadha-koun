BRAY Score Tracker — Android Studio source project

Features:
- MR, MB, RS, DS score entry with automatic totals and ranking
- Up to 18 rounds per game
- Local device saving (localStorage)
- New Game saves the current match to history
- Load a saved match and reset current game without deleting history
- Create a shareable scoreboard PNG; browser support determines direct sharing vs saving image

To build an APK:
1. Install Android Studio on a computer.
2. Open this project folder (BRAY_Score_Tracker_App) in Android Studio.
3. Allow Gradle sync and install Android SDK Platform 35 if prompted.
4. Select Build > Build Bundle(s) / APK(s) > Build APK(s).
5. The APK will be under app/build/outputs/apk/debug/app-debug.apk.

Note: This package is the editable Android Studio project, not a precompiled APK binary.
